# One Word for the Boss

One word, 12 characters: the boss, summed up in a single word — entered in the [make.fun bounty](https://make.fun/c/u-swift-badger-44-one-word-for-the-boss-6b48c735).

## The entry

> Micromanager

12 characters, exactly one word. No setup, no punchline needed: every office worker reads it and instantly pictures the boss hovering over their shoulder, re-reading the email they just sent. The classic one-word boss roast — sharp, funny, lands in a single beat.

## Run

```sh
node main.ts   # writes the entry to /output/entry.txt
```

`main.ts` writes the word to `/output/entry.txt` and enforces the gate itself: exactly one word, 1–120 characters, a single non-blank line.
